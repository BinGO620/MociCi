# 默词 MociCi

本 App 出厂不内置任何词库、例句、搭配或音频。词本完全由你自己导入，保存在本机。

安装时手机需允许「安装未知来源应用」。首次打开是空词本，按下面的三步导入。

## 三步上手

1. 复制 App 里的「AI 生成词表」提示词，粘贴到任意 AI 对话里，让它生成词表。
2. 把 AI 输出的代码块整段复制，粘进「导入」页，点导入。
3. 确认摘要，开始学习。

## 词表格式（推荐：词典式纯文本）

```
abandon /əˈbændən/ v. 放弃；抛弃；遗弃
  - abandon oneself to 沉溺于
  - abandon hope 放弃希望

ability /əˈbɪləti/ n. 能力；才能
  - have the ability to do sth 有能力做某事
```

- 单词必须在行首，只含字母、`'`、`-`
- 音标可选，用 `/.../` 或 `[...]`
- 搭配行以 `-` 开头，或缩进两格
- 也支持 CSV / TSV / 竖线表格（可调列映射）和 JSON 数组

## 发音

默认用系统 TTS（en-US，语速 0.8），不需要联网。如果设备没装英语语音包，设置页会提示。

## 关于 AI

AI 只用于一件事件：拍照批改手写听写。键入听写完全在本机比较，不会发任何网络请求。
API Key 只保存在本机，不写进源码、不随导出或备份带走。

## 构建

```bash
tools/build.sh          # 产出 MociCi.apk
tools/build.sh --qa     # debuggable 包，仅用于截图/灌数据
node --test "tests/*.test.js"
```

需要 JDK 17 与 Android SDK 34 build-tools，无需 Gradle。

签名密钥在 `build/moci-release.jks`，密码在 `build/keystore.properties`。**这两个文件丢了就无法覆盖升级，只能卸载重装，请自行备份。**

## 在线 TTS（可选，默认关闭）

设置里可以填 URL 模板，用 `{text}` 占位，例如：

```
https://example.com/tts?lang=en&q={text}
```

文本会用 `encodeURIComponent` 编码。首次播放时才生成并缓存，失败自动回退系统 TTS。

## 数据

- 全部数据在本机 `files/` 私有目录
- 每次导入前自动备份，保留最近 7 份、总计不超过 50MB
- 删除的词保留在 `deleted.json`（最近 50 条），可在数据面板恢复
- 恢复备份前也会自动快照（`pre-restore`），误恢复可回退
- 清空会先备份，设置项保留

## Known Limitations（已知限制）

1. **长列表不做虚拟滚动，只显示前 N 条**：词本页前 300、短语视图前 400、错词分组每类前 100。截断时页面顶部会有橙色提示写明“仅显示前 N，共 M 个词，请用搜索缩小范围”，数据本身完整保留。万词级使用请依赖搜索。
2. **真机未验收**：开发环境没有 Android 设备，WebView 渲染、系统 TTS、相机拍照、SAF 导出、返回键与覆盖升级均未在设备上实测。相关逻辑已实现并有单元/浏览器测试覆盖，但“真机可用”未经实测。
3. **在线 TTS 默认关闭**：未提供真实端点，只用本地 mock 验证了 URL 编码、缓存与失败回退。
4. **列映射交互简单**：点击列名循环切换列号，未提供下拉或拖拽。
5. **备份是明文 JSON**：便于检查，不加密。
6. **单词拼写是主键，不可改名**：改拼写需删除后重建（删除可在「最近删除」恢复，但学习进度按新词从零开始）。
7. **不做词形还原**：`studies` 与 `study` 是两条记录；导入预览只提供启发式“疑似变形”提示，需手动合并。
8. **释义首次为准**：首次导入按“每词性 2 个、总计 4 个”截断，之后同词再导入的释义一律忽略（既不覆盖也不进冲突清单）。需要改释义请到词条详情手动编辑，手动编辑不受上限约束。
9. **TTS 首次初始化有延迟**：引擎在 App 启动时创建，但部分国产 ROM 的 `onInit` 仍需数百毫秒；实测前 1–2 次发音可能略慢，之后由预取缓存接管。
10. **卸载前必须手动导出**：数据只在本机 App 私有目录，卸载即清除。App 每天首次打开会写一份 `daily-{date}.json`（保留 7 天），但备份同样在这个目录里，卸载会一起消失。
11. **浏览器版有 4MB 存储上限**：`localStorage` 约 5MB，超过 4MB 会明确报错并建议改用 Android 版。
12. **不确定中文释义的短语题可能过于宽松**：手写照片判分对空格/连字符/撇号差异豁免（刻意设计），因此 `in to` 与 `into` 在手写模式下会被判对；键入模式严格判错。
13. **无释义词不参与听写**：没有中文释义的词不会出现在听写题里，也不计入答对率统计（避免必然答错拉低正确率），只在学习卡中按“仅凭发音”出现。

## 真机验证清单（上线前必须跑完）

按顺序在设备上逐项确认，任一项失败即视为未通过验收：

1. 冷启动进入空态，底部四个 tab 可切换，无白屏。
2. 粘贴提示词模板生成的一段词表并导入，摘要按钮数字与首页词数一致。
3. 导入后重启 App，词本仍在（原生文件存储生效，不是 localStorage）。
4. 学习卡翻面时能听到 en-US 发音；语速设置生效。
5. 设备缺少英语语音包时，首次进入学习只弹一次提示，且可跳转系统 TTS 设置。
6. 键入听写：大小写/首尾空格判对，拼错判错，全程无网络请求（可开飞行模式）。
7. 手写批改：相机能拍、能取回图片、能上传并返回逐题结果；空格缺失判对、真实拼写错误判错。
8. 返回键在学习/听写页先弹确认，取消后仍留在原题；在结果页回到首页。
9. 导出三种格式：JSON 可再导入恢复进度，CSV 用 Excel 打开中文不乱码。
10. 覆盖安装新版 APK 后数据仍在（签名密钥未变）；keystore 已另存备份。
